## 1. 개발 목표

21일차에 구현한 5단계 수배·자유 추격 시스템에서 플레이어가 추적 경비의 위치와 접근 방향을 더 쉽게 파악할 수 있도록 미니맵 정보를 보강한다.

초기에는 월드 공간에 경비의 실제 시야 범위를 넓은 빨간 영역으로 표시하는 방식을 검토했으나, 화면을 과도하게 가리고 시각 피로가 커지는 문제가 있어 최종적으로 월드 표시를 비활성화한다.

대신 수배 중인 경비의 위치를 미니맵에 표시하고, 적 주변의 작은 원형 고리와 현재 바라보거나 이동하는 방향의 강조 구간으로 접근 방향을 전달한다.

## 2. DetectionSensor 조회 정보 확장

기존 탐지 판정은 그대로 유지하면서 미니맵 표시 시스템이 경비의 실제 시야 기준을 읽을 수 있도록 조회 속성을 추가한다.

- 실제 시야 거리 조회 추가
- 실제 시야 각도 조회 추가
- 시야 충돌 마스크 조회 추가
- 실제 시야 기준 Transform 조회 추가
- 실제 시야 원점 월드 좌표 조회 추가

탐지 거리와 각도 자체의 밸런스 값은 변경하지 않는다.

---
## 3. 월드 공간 시야 표시 비활성화

초기 Day22 구현에서 사용한 넓은 월드 공간 시야 펄스는 최종 방식에서 사용하지 않는다.

`WantedVisionPulse`는 기존 컴포넌트와의 호환을 위해 파일과 타입을 유지하지만 활성화 시 자체적으로 비활성화된다.

이를 통해 이전 Day22 파일이 적용된 프로젝트에서도 별도의 프리팹·씬 정리 없이 월드 시야 표시가 나타나지 않도록 한다.

---
## 4. 미니맵 수배 경비 위치 표시

수배 단계가 1성 이상일 때 현재 활성 상태이며 살아 있는 `MapWantedGuardAgent`를 미니맵에서 조회한다.

각 경비의 월드 위치를 기존 `MapNavigationMath.WorldToViewport` 계산으로 미니맵 좌표에 변환한다.

현재 미니맵 표시 범위 안에 들어온 수배 경비는 작은 빨간 표식으로 항상 표시한다.

다음 상태에서는 표시하지 않는다.

- 수배가 없는 상태
- 미니맵 숨김 상태
- 전체 지도 표시 상태
- 사망한 수배 경비
- 현재 미니맵 범위 밖의 경비

---
## 5. 적 주변 방향 고리

각 수배 경비 표식 주변에 작은 원형 고리를 표시한다.

기본 고리는 옅은 빨간색으로 표시하고 경비가 현재 바라보는 방향의 일정 구간만 더 두껍고 진한 빨간색으로 강조한다.

기본 임시 표시값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| 적 중심 표식 | 7px |
| 고리 반경 | 10px |
| 기본 고리 두께 | 1.4px |
| 방향 강조 각도 | 70° |
| 방향 강조 두께 | 4.2px |
| 기본 고리 분할 | 28 |
| 방향 구간 분할 | 9 |

실제 탐지 범위를 그대로 넓게 그리지 않고 현재 접근·시선 방향을 읽기 위한 간단한 UI로 사용한다.

---
## 6. 방향 기준

경비에 `DetectionSensor.VisionSource`가 존재하면 해당 Transform의 전방 방향을 우선 사용한다.

별도 시야 기준이 없으면 `MapWantedGuardAgent`의 `transform.forward`를 사용한다.

월드 XZ 방향을 미니맵 화면 방향으로 변환한 뒤 해당 방향을 중심으로 약 70°의 고리 구간을 강조한다.

적 중심에서 강조 방향으로 짧은 보조선도 함께 표시해 작은 미니맵에서도 방향을 구분하기 쉽게 한다.

---
## 7. 런타임 자동 연결

`WantedVisionPulseBootstrap`은 씬에 별도 오브젝트를 수동 배치하지 않아도 런타임에 자동 생성된다.

부트스트랩은 `WantedMiniMapVisionOverlay`를 같은 오브젝트에 자동으로 추가하며 씬 전환 뒤에도 유지한다.

Domain Reload가 꺼진 프로젝트 설정을 고려해 `SubsystemRegistration` 시점에 정적 인스턴스 참조를 초기화한다.
