## 1. 개발 목표

본편 `Map` 씬에서 현재 위치와 주요 구역을 확인할 수 있는 월드 지도 시스템을 추가한다.

`M` 키로 전체 지도를 열고, `N` 키로 미니맵을 표시하거나 숨기며, `Shift+N`으로 미니맵 크기를 소형·중형·대형 순서로 변경한다.

전체 지도는 3×3 Terrain과 12×12 도로망, 주요 `MapPoint`, 플레이어 위치와 방향을 실제 월드 좌표를 기준으로 표시한다.

## 4. 지도 표시 데이터

전체 지도와 미니맵은 별도 고정 이미지가 아니라 현재 본편 월드 데이터를 사용한다.

- `MapWorldRoot.WorldSize`를 전체 지도 크기 기준으로 사용
- 3×3 Terrain 타일 경계 표시
- 12×12 도시 도로망 단순 선 표시
- `MapPoint` 주요 구역 위치 표시
- 린의 옥상 작업실·겹길·저류·유리관·첨탑 표시
- 플레이어 현재 위치를 흰색 표식으로 표시
- 플레이어 바라보는 방향을 별도 방향선으로 표시
- 확대 상태의 지도 바깥 표식은 그리지 않도록 범위 검사

---
## 5. 지도 좌표 계산

`MapNavigationMath`에서 월드 X/Z 좌표를 지도 화면 좌표로 변환한다.

- 월드 좌표 → 지도 사각형 좌표 변환
- 현재 지도 범위 안쪽 여부 계산
- 전체 지도 이동 중심 제한
- 전체 지도 확대 배율 → 실제 월드 표시 범위 변환
- 소형·중형·대형 미니맵 픽셀 크기 계산
- 미니맵 월드 표시 범위 제한

지도 좌표는 월드 원점을 기준으로 하며 미니맵은 플레이어를 중심으로, 전체 지도는 사용자가 이동한 지도 중심을 기준으로 계산한다.

## 8. 조작
