# 8일차 개발 일지

## 개발 목표

기존 기본 검술 전투를 방어·받아치기·자세 붕괴가 포함된 상호 전투 구조로 확장하고, E-02 검술 호위병과 전투 상태 UI를 통해 실제 1대1 검술 테스트가 가능하도록 구성한다.

## 작업 내용

- 플레이어 HP 100·자세 100 기반 `PlayerHealth` 전투 생존 구조 추가
- 마우스 오른쪽 버튼 기반 방어와 0.22초 받아치기 판정 추가
- 일반 방어 시 체력·자세 피해 감소 처리 추가
- 받아치기 성공 시 적 자세에 42 피해를 주고 `PARRY` 피드백을 표시하도록 추가
- 플레이어 자세가 0이 되면 잠시 이동·방어가 제한되는 자세 붕괴 상태 추가
- 적 자세가 0이 되면 약 2초간 행동 불가 후 일부 자세를 회복하도록 `EnemyActor` 수정
- E-01 순찰 경비가 자세 붕괴 중 이동·추격·수색을 중단하도록 `PatrolGuardAI` 수정
- 공격 중 방어 입력을 제한하고 방어 중 공격 입력을 제한하도록 플레이어 검술 상태 연동 수정
- 공격·방어·받아치기 상태에서 플레이어 발밑 방향 표시를 숨기도록 연동 추가
- E-02 검술 호위병용 추격·공격 AI 추가
- E-02 기본 공격 22·강 공격 36 피해와 공격 예고·후딜레이 구조 추가
- E-02 HP 130·자세 120·시야 20m/100도·청각 12m 기준 능력치 적용
- E-02 전용 장갑·바이저·발광 코어·장검 세부 모델링과 재질 추가
- 세 번째 공격마다 강 공격을 사용하는 E-02 공격 패턴 추가
- 적 머리 위 탐지·공격 예고·HP·자세 정보를 통합한 전투 UI 추가
- 공격 예고 게이지를 HP 바로 위에 배치하고 탐지·공격·HP·자세별 색상 구분 추가
- Unity 6 내장 글꼴 규칙에 맞춰 전투 UI 글꼴을 `LegacyRuntime.ttf`로 수정
- 기존 탐지 UI·자세 UI와 통합 전투 UI가 중복되지 않도록 UI 구성 정리
- 적 UI를 평상시 항상 표시하지 않고 탐지·공격·피해·자세 붕괴 상황에서만 표시하도록 수정
- 피해를 받은 적은 약 3초간 HP·자세 UI가 표시되도록 상태 기반 표시 기능 추가
- Idle 상태에서는 불필요한 EYE 탐지 행을 숨기도록 UI 표시 조건 수정
- `Defense` Input Action과 마우스 오른쪽 버튼 바인딩 추가
- 활성화된 InputActionAsset을 직접 수정할 때 발생하던 예외를 복제본 수정·재임포트 방식으로 수정
- Scene View의 PlayerInput 번개 아이콘을 숨기기 위한 에디터 정리 기능 추가
- Test 씬에 E-02와 8일차 전투 테스트 구성을 반영
