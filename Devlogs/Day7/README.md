# 7일차 개발 일지

## 개발 목표

플레이어의 바라보는 방향을 발밑 시각 요소로 표시하고, 잠입 상황에서 사용할 암살 기능과 기본 검술 전투를 실제로 테스트할 수 있도록 구성한다.

## 작업 내용

- `PlayerDirectionIndicator`를 추가해 플레이어 발밑 원형 링과 방향 화살표 표시 기능 추가
- 플레이어가 실제로 이동할 때만 방향 표시가 나타나도록 이동 상태 연동 추가
- 정지·공중 상태·공격·암살 중 방향 표시가 숨겨지도록 표시 조건 수정
- 경사면에서도 바닥 방향에 맞춰 링과 화살표가 배치되도록 바닥 추적 기능 추가
- `EnemyActor`를 추가해 적 HP·자세·사망·암살 가능 상태 구조 추가
- 기존 E-01 경비에 HP 100·자세 100·암살 가능 상태 연결 추가
- `PlayerAssassination`을 추가해 적 후방 접근과 거리 조건 기반 F키 암살 기능 추가
- 암살 가능 대상 접근 시 화면에 `[F] 암살` 안내가 표시되도록 추가
- F키 입력 시 일반 상호작용보다 암살을 우선 처리하도록 `PlayerInteraction` 수정
- 암살 중 플레이어 이동과 방향 표시를 잠시 비활성화하도록 연동 추가
- `PlayerCombatController`를 추가해 기존 Attack 입력 기반 기본 검 공격 기능 추가
- 절선 Prototype 검 모델과 금속·청록 발광 재질 추가
- 마우스 왼쪽 클릭으로 검을 휘두르고 전방 적에게 체력 28·자세 20 피해를 주도록 추가
- 공격 중 플레이어 방향 표시가 숨겨지고 공격 종료 후 복구되도록 연동 추가
- 적 HP가 0이 되면 AI·탐지·시야 영역·탐지 UI가 정지하도록 사망 처리 추가
- `AssassinationTestRobot`을 추가해 가만히 있는 암살 연습용 로봇 테스트 환경 추가
- `CombatTestRobot`을 추가해 기본 검 공격과 피해를 확인할 수 있는 전투 연습 환경 추가
- `ProjectKDay7CombatSetup`을 추가해 플레이어 전투 구성과 테스트 로봇 배치를 자동화하도록 추가
- Test 씬에 7일차 방향 표시·암살·전투 테스트 요소 반영
