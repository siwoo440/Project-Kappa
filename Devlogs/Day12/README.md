## 1. 개발 목표

11일차의 반동·탄 분산·총성·탄약 구조를 유지하면서 유령손·골목비·청룡선을 연결한다. 반자동과 자동 연사, 총기별 장착·조준 시간, 머리·몸통 피해의 차이를 구현하고, 공격에 따라 적 체력바가 실제로 줄어들도록 표시 문제를 수정한다.

---
## 2. 작업 내용

- 유령손·골목비·청룡선의 독립 무기 데이터·프리팹·재질 추가
- 권총·기관단총·돌격소총을 구분할 수 있는 모형과 기존 발사·재장전 연출 연결 추가
- `FirearmDefinition`에 발사 방식·장착 시간·조준 시간·이동 배율·머리 피해 설정 추가
- 유령손 클릭당 한 발과 골목비·청룡선 버튼 유지 연사 처리 추가
- `FirearmTriggerState`에 예정 시각 기반 발사 간격과 프레임당 예약 개수 제한 추가
- 버튼 해제·무기 교체·재장전·특수행동 중 남은 연사 예약 취소 처리 추가
- 중단 중 유지된 공격 입력은 버튼 해제 후 새 입력으로 재개하도록 처리 수정
- 장착 대기 이후 사격을 허용하고 조준 진행도에 따라 분산·시야각·감도를 연결하도록 수정

- 기존 총기별 장탄수·예비탄 보존과 재장전 취소 구조를 자동 연사에 연결하도록 수정
- `FirearmHitZone`과 `EnemyFirearmHitboxes` 기반 머리·몸통 전용 피격 영역 추가
- 기존 적 이동용 충돌체와 총기용 피격 영역의 검사 분리 추가
- 부위별 피해·거리 감쇠·적 방어율·방어 관통을 결합하는 피해 계산 추가
- 장비 선택 5·6·7번 입력과 총기 이름·발사 방식·피해 결과 HUD 표시 수정
- 부위별 피해·테스트 방어율 0%·50%를 비교하는 훈련 표적 추가
- 40m·70m 탄착 비교 표적과 탄약 보충·기록 초기화 단말기 추가
- 이전 검증용 권총 에셋을 유지하고 기본 장비 목록과 이전 진열에서만 제외하도록 수정
- 대표 총기 설정·발사 규칙·머리/몸통/벽 충돌 검사 메뉴 추가
- HP·자세·공격 예고·탐지 게이지를 실제 가로 너비로 갱신하도록 수정
- 체력바 영점 잔상 방지·수치 범위 보정·회복 후 재표시 처리 추가

아래 표는 최신 커밋의 `ProjectKDay12Catalog` 생성 코드에 기록된 초기 설정이다. 저장된 에셋을 이후 Inspector에서 변경하면 실제 실행값은 달라질 수 있다. 최종 밸런스 확정값은 아니다.

| 항목 | 유령손 | 골목비 | 청룡선 |
|---|---:|---:|---:|
| 무기 ID | GUN-P01 | GUN-S01 | GUN-A01 |
| 발사 방식 | 반자동 | 자동 | 자동 |
| 몸통 / 머리 피해 | 24 / 43 | 16 / 27 | 27 / 45 |

| 탄창 / 예비탄 | 10 / 60발 | 30 / 120발 | 30 / 120발 |
| 유효 거리 / 감쇠 종료 | 24 / 42m | 20 / 38m | 42 / 72m |

## 4. 체력바 버그 수정

증상은 공격 후 체력바의 채움 길이가 바뀌지 않는 것이었다. 기존 UI는 별도 Sprite 없이 `Image.Type.Filled`의 `fillAmount`를 갱신하는 구성이었으며, 이번 수정은 `SetGaugeFill`에서 `Image.Type.Simple`과 `RectTransform.anchorMax`를 사용해 남은 비율만큼 실제 표시 너비를 변경하도록 바꿨다.

- 현재 체력 비율에 따라 HP 막대 너비가 갱신되도록 수정
- 같은 생성 방식을 쓰는 자세·공격 예고·탐지 게이지에도 공통 갱신 방식 적용 수정
- 값 0에서 채움 이미지를 숨기고 값 증가 시 다시 표시하도록 수정
- NaN·무한대·음수·최대치 초과 값의 표시 범위 보정 추가
- 기존 색상·배치·상황별 표시·사망 시 숨김 조건 유지

수정 대상은 `Assets/_Project/Scripts/UI/EnemyCombatBillboardUI.cs`이다. 이번 체력바 수정에서는 공격력과 실제 체력 계산을 바꾸지 않았다. [검토한 UI 코드](https://github.com/siwoo440/Project-Kappa/blob/5a7b5cb2fbbe6369292e06c49a53ff05aae7d729/Assets/_Project/Scripts/UI/EnemyCombatBillboardUI.cs)에 네 게이지의 공통 갱신 연결이 포함되어 있다.
