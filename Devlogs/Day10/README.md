# 10일차 개발 일지

---
## 개발 목표

9일차 장비 관리 구조에 검증용 권총을 연결하고, 검·총 장착 전환부터 조준·단발 사격·명중·탄약 소모·재장전·보급까지 이어지는 총기 기본 흐름 구현.

검토 기준: `057b837e4c8c889937133b0ef9f3b3fffe070c60` (검토 당시 `main`, 커밋 메시지 `10`).

---
## 작업 내용

- 기존 WeaponData와 총기 모형·총구·재장전 설정을 연결하는 FirearmDefinition 추가
- 장탄수·예비탄·발사 간격·재장전 진행을 분리한 FirearmRuntimeState 추가
- 총기별 상태를 보관해 검으로 교체한 뒤에도 남은 탄약을 유지하는 구조 추가
- 기존 근접 무기와 총기를 하나의 장비 목록에서 선택하는 장착 전환 기능 추가
- 선택한 검 또는 총만 표시하고 검 공격과 총 사격이 동시에 실행되지 않도록 입력 분기 수정
- 권총의 화면 중앙 조준·단발 발사·사거리 제한·거리별 체력 및 자세 피해 추가
- 플레이어 몸에서 총구까지와 총구 주변·목표까지의 경로를 검사하는 엄폐 판정 추가
- 발사 간격과 빈 탄창 상태를 검사하고 성공한 발사에만 탄약을 소모하는 처리 추가
- 재장전 완료 시 탄창의 빈 공간만큼 예비탄을 옮기는 처리 추가
- 무기 교체·사망·자세 붕괴·특수행동 시 재장전을 취소하고 탄약을 보존하는 처리 추가
- 검증용 권총 프리팹·금속 재질·발광선·총구 효과·모형 반동·탄창 재장전 연출 추가
- 임시 전자 발사음과 기존 NoiseSystem의 총성 이벤트 연결 추가
- 기존 장비 HUD에 총기 이름·장탄수·예비탄·재장전 게이지·조준점·명중 표시 추가
- 조준·발사·재장전 중 플레이어 발밑 방향 표시가 숨겨지도록 연동 수정
- 기존 훈련장 보급대에 권총 장탄수와 예비탄 보충 기능 추가
- 적 사망 시 해당 적의 Canvas와 시야 부채꼴을 숨기도록 잔류 표시 처리 수정
- 플레이어 자세 붕괴 중 체력 피해를 허용하고 붕괴 시간이 재시작되지 않도록 피해 처리 수정
- 10일차 설정 메뉴에 입력·권총 데이터·프리팹·장착 참조·진열 모형 생성 기능 추가
- 설정 변경 전 Test 씬과 입력 파일 백업 및 이전 일차 재설정 보호 처리 추가
- 총기 설정 검증과 탄약 상태 규칙 검사 메뉴 추가

## 남은 검증 및 다음 일차

현재 사격은 화면 중앙 기준 단발이며, 총기 모형 반동과 기본 조준 확대가 연결된 상태. 비조준·조준 탄 분산, 누적 조준 반동, 이동·공중 정확도 보정과 소음기별 AI 청각 차이는 후속 범위.

원래 개발 계획의 10일차 항목 중 단발 이외 발사 모드, 머리·몸통 부위별 피해, 방어 관통 계산은 아직 완성된 것으로 기록하지 않음. 공통 구조 보완과 대표 총기 확장 단계에서 연결할 항목으로 관리.

11일차는 개발 계획 탭의 조준·반동·분산·탄약·재장전·총성 AI를 기준으로 진행. 이미 구현한 탄약과 재장전은 재작성하지 않고 회귀 검증 및 다중 장비 연결을 보완.

| 검증 항목 | 기대 결과 | 현재 검증 상태 |
|---|---|---|
| 권총·검 교체 후 발사 | 선택한 무기만 동작, 남은 탄약 유지 | 로컬 확인 필요 |

| 총구 앞 벽·벽 내부 총구 | 벽 너머 적에게 피해 없음 | 로컬 확인 필요 |
