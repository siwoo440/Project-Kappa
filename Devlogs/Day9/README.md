## 후속 보완 사항

---
### 1. 적 사망 후 UI 숨김 경로 보완 필요

[`EnemyActor.DisableGameplayComponents()`](https://github.com/siwoo440/Project-Kappa/blob/efe9d5f826243f15d1953d0b5a7123d616178563/Assets/_Project/Scripts/AI/EnemyActor.cs)는 사망 시 `EnemyCombatBillboardUI.enabled = false`로 UI 제어 스크립트를 먼저 비활성화한다. 반면 [`EnemyCombatBillboardUI`](https://github.com/siwoo440/Project-Kappa/blob/efe9d5f826243f15d1953d0b5a7123d616178563/Assets/_Project/Scripts/UI/EnemyCombatBillboardUI.cs)의 사망 시 Canvas 숨김은 `LateUpdate()`에만 있고 `OnDisable()` 정리가 없다.

코드상으로는 이미 표시 중인 Canvas가 사망 이후에도 남을 수 있는 경로다. UI 스크립트를 비활성화할 때 소유 Canvas도 숨기거나, 사망 알림에서 먼저 숨기도록 보완 필요. 실제 재현 검증은 미실시.

재검증 절차: 전투 UI가 표시된 적을 처치한 뒤 HP·자세 UI가 즉시 사라지는지 확인.

---
### 2. 플레이어 자세 붕괴 중 피해 무효화 의도 확인

[`PlayerHealth.TakeDamage()`](https://github.com/siwoo440/Project-Kappa/blob/efe9d5f826243f15d1953d0b5a7123d616178563/Assets/_Project/Scripts/Combat/PlayerHealth.cs)는 `dead || postureBroken`이면 체력·자세 피해를 모두 무시한다. 따라서 현재 코드에서 자세 붕괴는 행동 제한과 함께 추가 체력 피해도 받지 않는 상태다.

이 동작이 의도된 무적 시간인지는 확인되지 않았다. 행동만 제한하려는 설계라면 체력 피해 허용과 자세 재붕괴 방지를 분리하는 수정 필요. 이 항목은 9일차에 새로 만든 규칙이 아니라 기존 전투 코드의 검토 사항.

재검증 절차: 자세가 0이 된 직후의 추가 타격에서 HP가 유지되는지 확인하고, 의도한 결과를 확정.
