## 1. 개발 목표

12일차까지 구현한 유령손·골목비·청룡선과 총기 공통 시스템을 유지하면서 대표 산탄총 `문지기`와 대표 저격총 `천리안`을 추가한다.

동시에 기존 Test 맵을 실제 반복 훈련에 사용할 수 있는 넓은 사격 훈련장으로 확장하고, 플레이어 스폰과 실제 적 교전 구역을 분리한다. 고정 표적·이동 표적·장거리 표적·TTK 표적을 배치하고 피격 시 기계적으로 젖혀졌다가 자동 복귀하도록 구현한다.

## 2. 대표 총기 2종

- 무기 ID `GUN-H01` 추가

- 탄약을 한 발씩 넣는 삽입식 재장전 추가

기존 Test 씬을 삭제하지 않고 별도의 확장 훈련 구역을 연결했다.

- 플레이어 기존 스폰 위치 유지
- 스폰 구역과 확장 훈련장 사이 이동 단말기 추가
- 훈련장 바닥·벽·방호판·레일·사격 부스·난간·기둥·엄폐물 모델링 추가
- 안전 구역·사격 구역·실전 교전 구역을 색상과 구조로 구분
- 총기 진열·탄약 보급·표적 초기화 기능을 가진 훈련 단말기 추가
- 90m·150m 장거리 정밀 사격 구간 추가
- 실제 적을 사용하는 별도 교전 구역 추가

## 6. 반응형 훈련 표적

신규 반응형 표적은 총 10개를 기본 구성으로 사용한다.

| 종류 | 수량 | 특징 |
|---|---:|---|
| 고정 근거리 표적 | 3 | 맞으면 바로 접히는 기본 표적 |
| 이동 표적 | 3 | 좌우 레일 왕복 후 피격 시 정지·접힘 |
| 장거리 정밀 표적 | 2 | 90m·150m 정밀 사격 확인 |
| TTK 표적 | 2 | 150HP 누적 피해 계측, 고정 1·이동 1 |

이동형은 일반 이동 표적 3개와 TTK 이동 표적 1개를 포함해 총 4개가 움직인다.

### 피격 동작

1. 서 있는 상태에서 피격을 수용한다.
2. 이동 표적은 피격 순간 레일 이동을 정지한다.
3. 회전축을 기준으로 표적판이 약 88도 젖혀진다.
4. 넘어지는 동안 피격 콜라이더를 비활성화해 중복 명중을 막는다.
5. 약 2.5초 동안 누운 상태를 유지한다.
6. 자동으로 다시 일어난다.
7. 완전히 복귀한 뒤 피격 콜라이더와 이동을 다시 활성화한다.

기존 사격 표적에도 같은 접힘 구조를 연결하고 기존 탄착 기록 기능을 유지한다.

## 7. 훈련 사격 계측

- 탄약 소비 횟수와 펠릿 수를 분리해 발사 횟수 집계
- 여러 펠릿이 같은 표적에 맞아도 발사 명중률은 한 발 기준으로 한 번만 증가
- 산탄총은 실제 적중한 펠릿 수를 별도로 기록
- TTK 표적은 첫 발사 시점부터 표적 체력이 0이 되는 시점까지 기록
- 탄약 보급·표적 상태·탄착·TTK 기록을 훈련 단말기에서 초기화
