## 1. 개발 목표

22일차까지 구현한 수배·추격 시스템이 실제 도시 환경에서 더 자연스럽게 작동하도록 추격 AI의 정체 복구 기능을 추가하고, 오픈월드 도시 자체의 이동 공간과 시각적 밀도를 확장한다.

기존 지상 도시에는 고층 건물, 골목, 빈 블록 보강, 가로등을 추가하고, 겹길 시장 주변에는 지상 Terrain을 실제로 뚫어 별도의 지하 Terrain과 지하철역을 만든다.

지하철은 순간 이동 방식 대신 지상에서 계단으로 직접 걸어 내려갈 수 있도록 구성한다.

## 2. 수배 경비 추격 안정화

기존 수배 경비는 플레이어를 직접 추격하면서 고정 구조물을 여러 방향으로 우회했지만 건물 모서리·좁은 골목·막다른 구조에서 일정 시간 정체될 수 있었다.

`Map23GuardChaseStability`를 추가해 일정 시간 실제 이동량을 검사하고, 정체 상태에서는 더 큰 각도의 측면·후방 우회 방향을 선택하도록 보조한다.

기본 검사값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| 정체 검사 간격 | 0.8초 |
| 정체 판단 이동량 | 0.45m |
| 우회 복구 시간 | 1.15초 |
| 우회 보조 속도 | 2.8 |
| 장애물 검사 거리 | 2.2m |
| 장애물 검사 반경 | 0.32m |
| 근접 정체 판정 제외 거리 | 4m |

우회 후보 방향에서는 고정 장애물과 발밑 존재 여부를 함께 확인해 벽이나 낙하 지점으로 강제 이동하지 않도록 한다.

---
## 3. 추격 안정화 자동 연결

`Map23ChaseBootstrap`을 런타임 자동 생성 방식으로 추가한다.

- 활성·비활성 수배 경비 검색 추가
- 신규 수배 경비에 `Map23GuardChaseStability` 자동 연결 추가
- 씬 전환 뒤에도 부트스트랩 유지 추가
- Domain Reload 비활성 환경 정적 상태 초기화 추가
- 수배 해제 후 살아 있는 경비 철수 처리 추가

수배 단계가 0이 된 뒤 약 6초가 지나면 남아 있는 살아 있는 수배 경비를 풀 대기 상태로 복귀시킨다.

## 4. 고층 건물 확장

도시 전체에 무작위로 고층을 올리지 않고 구역 성격에 따라 고층화 범위를 제한한다.

### 기업형 고층 구역

동쪽 기업 구역을 중심으로 기존 건물의 `MainCollision.bounds.max.y`를 읽어 실제 옥상 바로 위에 상부 타워를 증축한다.

### 혼합 고층 구역

중앙 북부 일부 블록은 기존 저층·중층 건물과 섞이도록 일부 건물만 고층화한다.

고층 건물에는 다음 요소를 추가한다.

- 상부 타워 본체
- 층별 창문·네온 띠
- 옥상 기계실
- 안테나
- 상단 네온 라인

저류 산업지구와 시장 구역은 상대적으로 낮은 실루엣을 유지한다.

## 5. 골목 구조 보강

골목 소품을 고정 좌표에 단순 배치하지 않고 같은 블록의 실제 건물 `Bounds`를 읽어 두 건물 사이의 빈 공간을 계산한다.

골목 폭과 길이가 충분할 때만 다음 요소를 배치한다.

- 젖은 바닥
- 쓰레기통
- 화물 상자
- 머리 위 정비 프레임
- 벽면 네온
- 외벽 배관

쓰레기통과 상자 같은 충돌 요소는 중앙 이동로보다 건물 벽 쪽에 배치해 추격·파쿠르 동선을 완전히 막지 않도록 한다.

## 6. 빈 도시 공간 채우기

도시 중심 구역 중 기존 일반 건물이 부족한 블록에는 저층 보조 건물 묶음을 추가한다.

추가 요소는 다음과 같다.

- 메인 저층 건물
- 소형 점포 건물
- 일부 블록 소형 창고
- 옥상 마감
- 창문 띠
- 점포 차양
- 네온 간판
- 전기 박스
- 화물 상자

기존 두 개 이상의 일반 건물이 이미 있는 블록은 추가 생성을 생략한다.

최종 보정에서는 채움 건물 루트가 실제 지상 Terrain 표면 높이를 조회하도록 수정하고, 건물 자식의 Y값이 지면 높이를 이중으로 더하지 않도록 로컬 좌표 기준으로 변경한다.

---
## 7. 도로 가로등 확장

주요 가로·세로 도로 라인을 따라 반복 가로등을 배치한다.

가로등은 다음 요소로 구성한다.

- 콘크리트 받침대
- 금속 기둥
- 가로 지지대
- 램프 헤드
- 따뜻한 발광부

초기에는 고정된 `MapTerrainMath.Ground` 높이를 사용했으나, 지형 높이와 맞지 않아 떠 있거나 묻힐 수 있는 문제를 확인했다.

최종 보정에서는 각 가로등의 월드 XZ 좌표에서 실제 지상 Terrain을 찾고 `Terrain.SampleHeight`를 사용해 지면 높이를 계산하도록 수정한다.

가로등 내부 자식 오브젝트도 월드 좌표와 로컬 좌표가 섞이지 않도록 동일한 로컬 좌표 기준으로 정리한다.

## 8. 실제 지하 Terrain 생성

기존 초기 지하철 구현은 지하 구조물을 단순 박스 형태로 배치하고 자동 이동 트리거를 사용하는 방식이었다.

이를 수정해 별도의 지하 TerrainData를 실제 생성한다.

기본 지하 Terrain 크기는 다음과 같다.

| 항목 | 값 |
|---|---:|
| 지하 Terrain 가로 | 220m |
| 지하 Terrain 세로 | 150m |
| 지하 바닥 기준 Y | 약 1.75 |
| Heightmap Resolution | 129 |
| Alphamap Resolution | 64 |

지하 Terrain은 지상 3×3 Terrain과 다른 그룹으로 관리하고 자동 이웃 연결은 사용하지 않는다.

생성 에셋은 다음 위치에 저장한다.

```text
Assets/_Project/Generated/Map23/UndergroundTerrain/
```

## 9. 지상 Terrain 개구부와 실제 계단

겹길 시장의 `Block_06_05` 예약 부지를 기준으로 지하철 출입구를 구성한다.

기존 통짜 `PavedLot`은 비활성화한 뒤 계단 개구부를 제외한 바닥 패널을 다시 만든다.

지상 TerrainData에는 Unity Terrain Hole을 적용해 렌더와 TerrainCollider를 실제로 제거한다.

지상과 지하는 다음 구조로 연결한다.

```text
지상 Terrain
↓
Terrain Hole
↓
지하철 입구
↓
56단 시각 계단
↓
연속 보행 경사 충돌면
↓
UndergroundTerrain
```

계단은 약 56개의 단을 시각적으로 표시하고, 실제 플레이어 충돌은 계단 아래의 연속된 경사면을 사용해 CharacterController의 걸림을 줄인다.

TerrainData를 수정하기 전 기존 TerrainData 에셋을 `Assets/_Project/Backups/Day23/`에 복사한다.

## 14. 남아 있는 문제와 추후 보정 항목

Day23 기능은 다음 일차로 넘어가지만 환경 자동 배치에는 아직 세부 보정이 필요한 부분이 남아 있다.

- 일부 건물·가로등·소품의 높이 또는 위치가 부자연스러운 구역 존재
- 기존 Day16~Day18 구조와 Day23 추가 구조 사이 일부 중첩 가능성 존재
- 모든 도시 블록의 시각적 밀도가 동일하게 정리되지는 않음
- 지하철 계단·Terrain Hole 주변의 실제 플레이 충돌 추가 확인 필요
- 지하 공간에서 수배 경비·시민 AI가 지상과 동일하게 이동하도록 별도 경로 연결 필요
- 지하 Terrain과 대규모 추가 구조의 렌더 비용·LOD·Occlusion 최적화 미완료
