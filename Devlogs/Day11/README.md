# 11일차 개발 일지

## 개발 목표

10일차에 구현한 권총 사격·탄약·재장전 구조를 유지하면서 조준 상태와 이동 상태에 따른 탄 분산, 연속 사격 반동, 소음기와 총성 AI 반응을 연결해 총기 전투의 기본 감각을 검증한다.

## 작업 내용

- 비조준·조준 상태에 따른 기본 탄 분산 구조 추가
- 이동·앉기·공중 상태에 따른 탄 분산 보정 추가
- 연속 사격 시 분산 누적과 사격 중단 후 분산 회복 처리 추가
- 카메라 입력과 분리된 수직·좌우 사격 반동 누적·회복 기능 추가
- 조준 상태에서 반동과 시점 감도를 별도 비율로 줄이는 기능 추가
- 실제 탄 분산값을 화면 조준점 크기에 연동하도록 HUD 수정
- 총기별 반동·분산·조준 감도·소음기 수치를 관리하는 FirearmHandlingProfile 추가
- 총기별 누적 분산과 소음기 장착 상태를 유지하는 FirearmHandlingState 추가
- 권총 소음기 장착·해제 기능과 소음기 전용 외형·총구 위치 추가
- 소음기 사용 시 총성 전달 반경과 효과음 크기를 감소하도록 처리 추가
- 일반 총성과 소음기 총성 모두 가까운 경비가 들을 수 있도록 청각 판정 유지
- 총성을 들은 적이 플레이어 현재 위치가 아닌 발사 당시 위치를 조사하도록 탐지 처리 수정
- 총성 청취 시 일반 소음보다 높은 의심도와 조사 시간을 적용하도록 DetectionSensor 수정
- 5m·15m·25m 거리 표적과 실제 탄착 위치 기록 기능 추가
- 사격 횟수·표적 명중 횟수 기반 훈련용 명중률 표시 추가
- 총성 청취 범위를 확인할 수 있는 근거리·원거리 청취 표시 장치 추가
- 사격 기록·탄착 흔적·청취 기록과 탄약을 초기화하는 훈련 단말기 추가
- Day 11 사격장 자동 구성과 반동·분산·청각 설정 검증 메뉴 추가
- 기존 탄약·재장전·검·총 장비 교체 구조와 11일차 기능 연동 유지
