## 1. 개발 목표

23일차에 추가한 실제 지하 Terrain과 지하철 계단을 수배 경비 추격 시스템에 연결한다.

플레이어와 경비가 지상과 지하 중 어느 층에 있는지 구분하고, 서로 다른 층에 있을 때 경비가 플레이어 좌표를 향해 지면이나 천장에 계속 막히는 대신 실제 계단을 이용해 층을 이동하도록 구성한다.

지하에서 플레이어를 놓쳤을 때는 승강장과 서비스 통로를 이용한 분산 수색으로 전환하고, 미니맵에서는 같은 층과 다른 층의 수배 경비를 구분해 표시한다.

23일차에 남은 지상 자동 배치 문제를 보완하기 위해 Terrain 높이 기반 배치 검수·자동 보정 메뉴도 추가한다.

## 2. 지상·지하 층 판정

`Map24LayerNavigation`을 추가해 Day23에서 생성한 지하 구조를 자동으로 검색한다.

연결 대상은 다음과 같다.

```text
Day23_UrbanChaseExpansion
├─ UndergroundTerrain
└─ Subway_MainStair
   ├─ Step_00
   ├─ Step_01
   ├─ ...
   └─ Step_55
```

`Map23CityExpansionMarker.UndergroundTerrain`을 통해 실제 지하 Terrain을 연결하고, `Subway_MainStair` 아래의 `Step_*` 오브젝트를 계단 이동 지점으로 등록한다.

첫 계단은 지상 연결점, 마지막 계단은 지하 연결점으로 사용한다.

지상과 지하의 기본 판정은 다음 조건을 함께 사용한다.

- 지하 Terrain의 XZ 범위 안에 있는지 확인
- 지상·지하 계단 중간 높이보다 아래인지 확인

지하 구조가 아직 준비되지 않은 경우에는 기존 도시 지면 높이를 기준으로 대체 판정한다.

---
## 3. 실제 계단 경로 등록

`Step_00`부터 마지막 계단까지 이름의 숫자 순서로 정렬해 실제 이동 경로로 사용한다.

경비가 다른 층의 플레이어를 추적해야 할 때 현재 위치에서 가까운 계단 지점을 찾고, 지상에서 지하로 내려갈 때는 첫 계단부터 마지막 계단 방향으로 이동한다.

지하에서 지상으로 올라갈 때는 같은 경로를 역방향으로 사용한다.

계단 경로는 Day23에서 생성한 실제 경사 충돌면과 함께 사용하므로 순간 이동으로 층을 전환하지 않는다.

---
## 4. 수배 경비 지상·지하 추격

`Map24GuardLayerAgent`를 모든 수배 경비에 자동 연결한다.

경비와 플레이어가 같은 층이면 기존 `MapWantedGuardAgent`의 자유 추격을 그대로 사용한다.

서로 다른 층이면 다음 구조로 전환한다.

```text
서로 다른 층 감지
↓
기존 직접 추격 일시 중지
↓
현재 위치와 계단 연결점 확인
↓
지하철 계단 이동
↓
목표 층 도착
↓
기존 추격 AI 복구
```

계단 이동 중에는 Day21의 직접 추격과 Day23의 정체 복구 기능이 동시에 캐릭터를 이동시키지 않도록 일시 중지한다.

목표 층에 도착하면 기존 수배 AI와 정체 복구 기능을 다시 활성화한다.

## 5. 계단 이동 기본값

| 항목 | 값 |
|---|---:|
| 계단 지점 도착 거리 | 1.15m |
| 일반 경비 계단 이동 속도 | 5.2 |
| 정예 경비 계단 이동 속도 | 6.1 |
| 지하 수색 이동 속도 | 4.2 |
| 지하 수색 지점 도착 거리 | 1.6m |
| 지하 수색 대기 시간 | 1.3초 |

계단 이동에서는 여러 계단 단을 한 번에 건너뛰어 다음 목표를 선택하고, CharacterController 중력을 별도로 적용해 Day23의 경사 충돌면을 따라 이동하도록 구성한다.

## 6. 지하 분산 수색

경비와 플레이어가 모두 지하에 있으며 직접 시야와 5초 공유 위치가 모두 사라진 경우 기존 자유 좌표 수색 대신 지하 전용 수색 지점을 사용한다.

수색 지점은 다음 구역에 분산된다.

- 북쪽 승강장 서쪽
- 북쪽 승강장 중앙
- 북쪽 승강장 동쪽
- 남쪽 승강장 서쪽
- 남쪽 승강장 중앙
- 남쪽 승강장 동쪽
- 서비스 통로 입구
- 서비스 통로 중앙
- 서비스 통로 끝
- 지하 계단 하단

경비 Instance ID와 수색 순번을 조합해 여러 경비가 같은 수색 지점만 반복해서 선택하지 않도록 한다.

각 지점에 도착하면 짧은 시간 주변을 회전하며 확인한 뒤 다음 수색점으로 이동한다.

## 7. 런타임 자동 연결

`Map24Bootstrap`을 추가해 씬이나 프리팹에 수동으로 컴포넌트를 연결하지 않아도 기능이 동작하도록 구성한다.

런타임에서 활성·비활성 `MapWantedGuardAgent`를 주기적으로 검색한다.

`Map24GuardLayerAgent`가 없는 경비에는 자동으로 컴포넌트를 추가한다.

Domain Reload가 비활성화된 Unity 환경에서도 이전 플레이 인스턴스가 남지 않도록 `SubsystemRegistration` 시점에 정적 참조를 초기화한다.

## 8. 미니맵 층 구분

기존 `WantedMiniMapVisionOverlay`를 수정해 플레이어와 경비의 층 관계를 표시한다.

### 같은 층

기존 22일차 표시를 그대로 사용한다.

- 진한 빨간 적 위치 표식
- 원형 고리
- 경비가 바라보는 방향 강조

### 다른 층

다른 층의 경비는 흐린 빨간색으로 표시한다.

플레이어 기준으로 경비가 위층에 있으면 `↑`, 아래층에 있으면 `↓`를 표시한다.

```text
같은 층
→ 빨간 점 + 방향 고리

다른 층
→ 흐린 점 + 흐린 고리 + ↑ 또는 ↓
```

이를 통해 지하에 있는 플레이어가 지상의 경비를 같은 높이의 적으로 오인하지 않도록 한다.

## 9. 지상 배치 자동 검수·보정

23일차 도시 확장에서 일부 자동 생성 요소의 높이와 위치가 부자연스러운 문제가 남아 있어 `ProjectKDay24PlacementValidation`을 추가한다.

메뉴 경로는 다음과 같다.

```text
Project K
→ Day 24
→ Validate And Fix Surface Placement
```

검수 대상은 다음과 같다.

- `FillCluster_*` 저층 채움 건물
- `Alley_*` 골목 디테일
- `RoadStreetLights/StreetLight` 가로등

각 요소의 현재 XZ 위치에서 실제 지상 Terrain을 찾고 `Terrain.SampleHeight`로 실제 표면 높이를 계산한다.

계산된 Terrain 높이와 현재 오브젝트 높이가 다르면 루트 Transform의 Y 위치를 자동으로 보정한다.
