# 6일차 개발 일지

## 개발 목표

D-01 회전 감시 카메라를 Test 훈련장에 추가하고, 카메라와 E-01 경비의 감시 방향과 범위를 플레이어가 직관적으로 확인할 수 있도록 시각화한다.

## 작업 내용

- `D01SimplePan`을 추가해 D-01 카메라 회전축이 좌우로 왕복 회전하도록 추가
- D-01 카메라 회전 범위를 -55도~55도로 구성하고 회전 속도 45도/초 기준 추가
- Stealth 훈련 구역에 D-01 감시 카메라 2대를 자동 배치하도록 추가
- D-01에 받침대·지지 기둥·회전축·본체·바이저·렌즈·상태등·전원 코어 세부 모델링 추가
- D-01에 시야 거리 20m·시야각 70도 탐지 센서 연결
- D-01에 기존 눈 아이콘과 탐지 게이지 Billboard UI 연동 추가
- `VisionSectorVisual`을 추가해 감시 범위를 반투명 부채꼴 Mesh로 표시하도록 추가
- E-01 감시 범위를 18m·90도 기준의 연한 빨간색 부채꼴로 표시하도록 추가
- D-01 감시 범위를 20m·70도 기준의 연한 빨간색 부채꼴로 표시하도록 추가
- E-01 본체 회전과 감시 부채꼴 방향이 함께 회전하도록 연결
- D-01 RotationPivot 회전과 감시 부채꼴 방향이 함께 회전하도록 연결
- 감시 영역 Mesh의 그림자·반사·깊이 쓰기를 제한해 테스트용 시각화로 구성
- 감시 영역이 바닥과 겹치지 않도록 소폭 높이를 보정해 Z-fighting 방지
- Test 씬의 DetectionSensor 대상에 감시 부채꼴 시각화를 자동 연결하는 설정 도구 추가
