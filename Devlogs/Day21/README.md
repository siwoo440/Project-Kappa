## 1. 개발 목표

20일차에 추가한 시민·자동차 생활 시스템을 실제 전투·범죄 시스템과 연결한다.

시민과 차량이 총기·검·폭발 피해를 받고 사망·파괴될 수 있도록 만들고, 플레이어 범죄가 Heat와 0~5성 수배 단계로 이어지도록 구성한다.

수배 단계가 높아질수록 추적 반경과 병력 수, E-02 정예 비율을 늘리고, 플레이어가 시야에서 벗어나 추가 범죄를 저지르지 않으면 시간이 지나며 수배 단계가 점차 감소하도록 구성한다.

추가 검증 과정에서 수배 경비가 횡단보도 보행 그래프에 모이는 문제를 확인해, 수배 경비와 도주 시민의 이동 방식을 자유 이동 구조로 수정한다.

## 7. 위치 공유와 수배 해제

한 수배 경비가 플레이어를 직접 확인하면 전체 수배 경비가 약 5초 동안 최신 플레이어 위치를 공유한다.

직접 발견이 계속되면 공유 위치와 만료 시간이 계속 갱신된다.

직접 발각과 공유 추적이 모두 끝나면 마지막 확인 위치 주변 수색 상태로 전환한다.

수배 감소 시작 대기 시간은 다음과 같다.

| 수배 | 미발각 대기 |
|---|---:|
| ★ | 8초 |
| ★★ | 12초 |
| ★★★ | 18초 |
| ★★★★ | 24초 |
| ★★★★★ | 30초 |

Heat는 한 번에 제거되지 않고 점진적으로 감소하며, 임계값을 통과할 때마다 별 단계가 하나씩 낮아진다.

- 약 8m 이내 근거리 360도 인지 추가
- 다른 수배 경비·시민·차량이 시야를 완전히 막지 않도록 수정
- 건물·벽·고정 구조물은 계속 시야 장애물로 유지
- 직접 발견 시 전체 경비 5초 위치 공유 유지

## 9. 수배 경비 자유 추격·수색

초기 수배 경비는 Day20 시민용 보행·횡단보도 그래프를 사용했다.

해당 그래프는 13×13 교차로 모서리 중심의 성긴 구조이며, 플레이어 위치를 향한 Greedy 이웃 선택 방식과 결합되어 여러 경비가 같은 교차로·횡단보도 노드에 모이는 문제가 있었다.

이를 다음 구조로 수정했다.

```text
플레이어 발견
↓
보행 그래프 사용 안 함
↓
플레이어 위치로 직접 이동
↓
고정 구조물만 간단히 우회
```

- 수배 경비의 추격에서 횡단보도 길찾기 제거
- 5초 공유 위치 추적에서도 보행 그래프 제거
- 수색 위치를 보행 노드에 스냅하지 않고 자유 좌표로 계산
- 경비별 수색 방향·거리 분산
- 정면이 막히면 좌우 여러 각도로 간단한 장애물 우회
- 수배 경비끼리 물리 충돌을 무시해 집결·막힘 현상 완화

## 10. 도주 시민 자유 이동

평상시 시민은 기존 도시 생활 구조를 유지한다.

```text
평상시
→ 인도·횡단보도 그래프 사용
→ 차량 접근 시 횡단 대기
```

총성·피격 등으로 `Flee` 상태가 되면:

```text
도주
→ 보행 노드 목적지 해제
→ 횡단보도 대기 해제
→ 위협 반대 방향으로 직접 이동
```

하도록 수정했다.

- 도주 중 횡단보도 길찾기 제거
- 도주 중 차량 대기 규칙 제거
- 위협 반대 방향 기반 자유 이동 추가
- 시민별 좌우 분산으로 한 줄 겹침 완화
- 벽·건물 등 고정 구조물 간단 우회 추가
- 도주 종료 후 현재 위치와 가장 가까운 보행 노드로 재연결
- 평상시 시민 횡단보도 생활 규칙은 유지
