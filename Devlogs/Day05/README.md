# 5일차 개발 일지

## 개발 목표

4일차에 구현한 시야·청각 탐지 기반 위에 실제 E-01 순찰 경비를 추가하고, 탐지 진행도를 머리 위 UI로 시각화해 잠입 상황을 직접 확인할 수 있도록 구성한다.

## 작업 내용

- `DetectionBillboardUI`를 추가해 탐지 대상 머리 위에 월드 공간 UI 표시 기능 추가
- 눈 아이콘과 탐지 게이지를 나란히 배치해 탐지 진행도를 시각적으로 확인하도록 추가
- Idle·Suspicious·Detected·Searching 상태에 따라 탐지 UI 색상이 변경되도록 추가
- 탐지 UI가 항상 플레이어 카메라 방향을 바라보도록 Billboard 처리 추가
- 탐지 UI가 적 본체 회전에 영향을 주지 않도록 UI 회전 구조 수정
- Test 씬의 `DetectionSensor` 보유 대상에 탐지 UI를 자동 연결하는 설정 도구 추가
- 기존 센서용 `DetectionGuard_A/B`를 실제 E-01 경비 오브젝트로 교체
- E-01 경비 2명을 Stealth 훈련 구역에 배치하도록 추가
- E-01 경비에 머리·바이저·몸통·팔·다리·장비·검집 형태의 세부 모델링 추가
- E-01 경비에 시야 18m·시야각 90도·청각 10m 탐지 센서 연결
- E-01 경비의 기본 순찰 속도 3.5m/s와 추격 속도 5.0m/s 기준 추가
- `PatrolGuardAI`를 추가해 순찰·소음 조사·추격·수색·순찰 복귀 행동 구조 추가
- 경비별 순찰 경로와 Stealth 구역 내 순찰 위치를 자동 구성하도록 추가
- 플레이어 발견 시 추격하고 놓친 뒤 마지막 위치를 수색하도록 행동 연결
- 기존 탐지 시스템과 E-01 순찰 AI·머리 위 탐지 UI를 연동하도록 추가

## 확인 결과

- 원격 `main` 최신 커밋은 4일차 커밋으로 확인
- 원격 저장소에 `PatrolGuardAI.cs`가 아직 존재하지 않는 상태 확인
- 5일차 탐지 UI와 E-01 순찰 경비 작업은 새 커밋으로 추가해야 하는 상태
- 실제 Unity Play Mode에서 순찰 경로·추격 거리·탐지 UI 크기와 위치는 플레이 테스트에 따라 추가 조정 필요
