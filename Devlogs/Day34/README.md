## 1. 개발 목표

33일차까지 M-02 잠입 암살 임무와 목표 안내 UI를 구현했다.

34일차에서는 ESC를 눌러 진입하는 공통 시스템 메뉴를 만들고, 저장·불러오기·설정·나가기 기능을 한 화면에서 관리할 수 있도록 구성한다.

또한 저장·불러오기와 설정 UI의 가독성을 높이고, 진행 상황 손실 가능성이 있는 불러오기와 게임 종료에는 별도 확인창을 추가한다.

## 2. ESC 메뉴 기본 구조

일반 플레이 중 ESC를 누르면 왼쪽 메뉴바를 표시한다.

```text
계속하기
저장
불러오기
설정
나가기
```

처음 ESC를 눌렀을 때 오른쪽에는 별도의 메뉴 문구를 표시하지 않고 블러 처리된 플레이 화면만 유지한다.

저장·불러오기·설정을 선택한 경우에만 오른쪽 콘텐츠 영역에 해당 페이지를 표시한다.

## 3. ESC 메뉴 중 일반 HUD 숨김

`Map30UITheme.HideGameplayHUD`에 ESC 메뉴 상태를 연결했다.

ESC 메뉴가 열리면 다음과 같은 일반 플레이 HUD가 숨겨진다.

```text
HP / 자세
미니맵
수배 HUD
QA HUD
임무 단말기 HUD
목표 화살표
장비 HUD
조준점
상호작용 안내
```

왼쪽 ESC 메뉴바와 사용자가 직접 연 저장·불러오기·설정 콘텐츠만 표시한다.

## 4. ESC 메뉴 입력 잠금

메뉴가 열린 동안 다음 플레이 입력을 차단한다.

```text
플레이어 이동
카메라 회전
지도 입력
Tab 임무 창 입력
진행 중 총기 행동
```

`Time.timeScale`을 0으로 설정하고 커서를 표시한다.

메뉴를 닫으면 열기 전 상태를 복원한다.

## 5. 오른쪽 블러 배경

ESC 메뉴를 표시하기 전에 현재 플레이 화면을 캡처한다.

캡처 이미지를 저해상도로 축소하고 Box Blur를 적용해 오른쪽 배경으로 사용한다.

슬롯 미리보기에는 블러 전 원본 축소 이미지를 사용한다.

## 6. 저장·불러오기 슬롯

저장·불러오기는 10개의 수동 슬롯을 사용한다.

```text
01 02 03 04 05
06 07 08 09 10
```

각 슬롯에는 다음 정보를 표시한다.

```text
플레이 화면 미리보기
현재 임무
현재 목표
저장 시각
크레딧
```

빈 슬롯은 `NO DATA`로 표시한다.

## 7. 저장 데이터 구조

저장 데이터는 JSON으로 관리한다.

슬롯별 파일은 다음 구조를 사용한다.

```text
slot_01.json
slot_01.backup.json
slot_01.png
```

현재 JSON이 손상된 경우 백업 JSON을 다시 시도한다.

## 8. 저장 범위

현재 저장 시스템은 다음 플레이 상태를 기록한다.

```text
플레이어 위치·회전
체력·자세
임무 상태
현재 Objective
임무 물품 보유·인계
체크포인트
보상 지급 기록
크레딧
선택 시스템 상태
소모품 수량
```

현재 프로젝트에 선택 시스템이 존재하지 않는 경우 Reflection을 사용해 해당 저장 항목을 건너뛸 수 있게 구성한다.

## 9. 설정 상단 탭

설정 페이지 상단에 작은 버튼을 가로로 배치한다.

```text
[ 그래픽 ] [ 사운드 ] [ 조작 ] [ 게임플레이 ]
```

왼쪽 ESC 메뉴는 유지하고 선택한 설정 탭의 내용만 오른쪽 설정 영역에서 교체한다.

## 10. 그래픽 설정

그래픽 탭에서 다음 옵션을 제공한다.

```text
해상도
화면 모드
그래픽 품질
수직 동기화
FPS 제한
```

화면 모드는 다음 세 가지를 순환한다.

```text
전체 창 모드
독점 전체 화면
창 모드
```

FPS 제한은 다음 값을 사용한다.

```text
무제한
30 FPS
60 FPS
120 FPS
144 FPS
```

## 11. 사운드 설정

사운드 탭에서 다음 옵션을 제공한다.

```text
전체 음량
전체 음소거
```

현재는 `AudioListener.volume`을 사용해 전체 게임 음량에 적용한다.

## 12. 조작 설정

조작 탭에 다음 옵션을 추가했다.

```text
마우스 감도
게임패드 감도
Y축 반전
```

기존 `ThirdPersonCamera`의 마우스 감도와 게임패드 회전 속도에 연결한다.

Y축 반전도 실제 카메라 상하 입력 계산에 반영한다.

## 13. 게임플레이 설정

게임플레이 탭에 다음 옵션을 추가했다.

```text
미니맵 표시
미니맵 크기
G 목표 안내 시간
```

미니맵 크기는 다음 단계로 관리한다.

```text
소형
중형
대형
```

G 목표 안내 표시 시간은 2초에서 8초 사이로 조절한다.

## 14. 설정 저장 파일

게임 진행 세이브와 사용자 환경 설정을 분리한다.

```text
Application.persistentDataPath/
└─ ProjectK/
   ├─ settings.json
   ├─ settings.backup.json
   └─ Saves/
```

진행 데이터는 슬롯 JSON에, 환경 설정은 `settings.json`에 저장한다.

## 15. 설정 공통 하단 버튼

모든 설정 탭 아래에 다음 버튼을 공유한다.

```text
기본값 복원
변경 취소
적용 및 저장
```

`기본값 복원`은 편집값만 초기화한다.

`변경 취소`는 아직 적용하지 않은 변경을 실제 설정값으로 되돌린다.

`적용 및 저장`은 실제 시스템에 반영한 뒤 `settings.json`에 기록한다.

## 16. 설정 UI 확대

설정 화면의 제목, 탭, 섹션 제목, 옵션 라벨, 값, 버튼과 설명을 기존보다 크게 조정했다.

작은 화면에서는 설정 내용이 잘리지 않도록 스크롤 가능한 구조를 사용한다.

## 17. 저장·불러오기 UI 글자 2배 확대

저장·불러오기 화면의 주요 글자 크기를 두 배로 확대했다.

```text
SAVE / LOAD 제목
34 → 68

슬롯 번호
10 → 20

슬롯 임무 제목
12 → 24

목표·날짜·크레딧
9 → 18

NO DATA
16 → 32

하단 안내문
11 → 22

저장·불러오기·삭제 버튼
12 → 24
```

큰 글자가 겹치지 않도록 카드 내부 정보 영역과 하단 버튼 크기도 함께 조정했다.

## 18. 나가기 버튼

왼쪽 ESC 메뉴의 설정 버튼 바로 아래에 `나가기` 버튼을 추가했다.

```text
설정
나가기
```

나가기는 즉시 게임을 종료하지 않고 별도 확인창을 표시한다.

## 19. 불러오기 확인창

저장 슬롯에서 `불러오기` 버튼을 누르면 즉시 데이터를 복원하지 않는다.

```text
저장 데이터 불러오기

SLOT XX의 저장 데이터를 불러오면
현재 저장되지 않은 진행 상황을 잃을 수 있습니다.

정말 저장 데이터를 불러오시겠습니까?

[취소] [불러오기]
```

확인을 선택해야 실제 `LoadSlot`을 실행한다.

## 20. 종료 확인창

나가기 버튼을 누르면 다음 경고창을 표시한다.

```text
게임 종료

저장하지 않은 진행 상황은 사라질 수 있습니다.
정말 게임을 종료하시겠습니까?

[취소] [나가기]
```

빌드에서는 `Application.Quit()`으로 종료한다.

Unity Editor에서는 Play Mode를 종료한다.

## 21. 경고창 입력 차단

불러오기 또는 게임 종료 확인창이 표시된 동안 뒤쪽 메뉴 입력을 비활성화한다.

```text
계속하기
저장
불러오기
설정
나가기
저장 슬롯
삭제
```

확인 또는 취소를 선택한 뒤에만 다시 메뉴 입력을 허용한다.

## 22. 경고창 ESC 처리

별도 확인창이 열린 상태에서 ESC를 누르면 전체 ESC 메뉴를 닫지 않는다.

```text
경고창 열림
↓
ESC
↓
경고창만 취소
↓
ESC 메뉴 유지
```
