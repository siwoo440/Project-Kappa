# 3일차 개발 일지

## 개발 목표

기본 이동 시스템 위에 벽 달리기·벽 오르기·벽 점프·난간 이동과 이동 에너지 시스템을 추가하고, 이후 개발 기능을 반복 검증할 수 있는 통합 훈련장을 구축한다.

## 작업 내용

- `MovementEnergy`를 추가해 파쿠르 전용 이동 에너지 소모·회복 구조 추가
- `PlayerParkour`를 추가해 좌우 벽 달리기·정면 벽 오르기·벽 점프 기능 추가
- 같은 벽에 즉시 재진입하는 반복 동작을 제한하는 재진입 쿨다운 추가
- 난간 감지·매달리기·좌우 이동·올라가기·놓기 기능 추가
- 파쿠르 상태에서 기본 이동과 파쿠르 이동이 동시에 적용되지 않도록 이동 제어 구조 수정
- 벽 달리기 중 이동 에너지가 지속 소모되고 에너지 부족 시 강제 이탈하도록 추가
- 일반 이동과 난간 상태에서 이동 에너지가 회복되도록 추가
- 벽 달리기 방향에 따라 3인칭 카메라가 좌우로 부드럽게 기울어지는 연출 추가
- 파쿠르 종료와 벽 점프 시 카메라 기울기가 원래 각도로 복귀하도록 수정
- Crouch 액션에 `Left Ctrl` 키보드 바인딩을 추가하도록 입력 설정 보정
- Test 씬을 이동·점프·앉기·카메라·벽 달리기·벽 점프·벽 오르기·난간 검증이 가능한 훈련장으로 확장
- 잠입·전투·무기·AI·저장·미션·상점 기능을 이후 일차에 시험할 수 있는 예비 테스트 구역 추가
- 파쿠르 표면 전용 `ParkourSurface` 레이어를 자동 구성하도록 수정
- 훈련장 생성용 재질과 구역별 시각 구분 구조 추가
- 기존 Test 씬 바닥과 새 훈련장 바닥이 중첩되며 발생하던 Z-fighting 현상 수정
- 기존 테스트 지오메트리를 정리하고 훈련장 바닥 높이를 분리해 표면 깜빡임 수정

- 3일차 작업은 새 커밋으로 추가해야 하는 상태
