## 1. 개발 목표와 완료 범위

기존 Test 훈련센터와 분리된 본편용 `Map` 씬을 만들고, 실제 Unity Terrain 9개를 3×3으로 연결한 첫 오픈월드 외부 공간을 제작한다.

린의 옥상 작업실을 시작점으로 저류·겹길·유리관·첨탑의 외부 랜드마크와 도로를 구성하고, 미션을 배치하기 전 플레이어가 주요 구역을 자유롭게 이동하고 거점으로 돌아올 수 있는 기반을 만든다.

이번 일차는 도시 외부 구조와 탐험 기반을 만드는 단계다. 미션·상시 경비·월드 저장·최종 도시 아트는 완료 범위에 포함하지 않는다.

## 3. 월드와 Terrain 구성

| 항목 | 현재 구성 |
|---|---|
| Terrain 배치 | 3 × 3 |
| Terrain 수 | 9 |
| 기본 타일 크기 | 512m × 512m |
| 전체 기본 크기 | 1,536m × 1,536m |
| 높이 해상도 | 타일당 257 × 257 |
| Terrain 높이 범위 | 160m |
| 도시 기본 지면 | 약 16m |
| Terrain 표면 | Ground / Rock / Moss |
| 도시 블록 | 12 × 12 외부 블록 |
| 본편 씬 | `Assets/_Project/Scenes/Map.unity` |

Terrain 타일은 각각 별도의 TerrainData 에셋을 사용한다. 높이 계산은 타일 로컬 좌표가 아니라 전체 월드 격자 좌표를 사용해 인접 타일의 공유 경계가 같은 값을 갖도록 구성한다.

Terrain의 이웃 관계는 MapWorldRoot가 실행과 씬 활성화 시 다시 연결한다.

## 5. 플레이어와 탐험

Map 씬은 기존 전투·총기·파쿠르 코드를 새로 복제해 작성하지 않고 기존 플레이어 구성을 재사용한다.

- 린의 옥상 작업실을 시작 및 추락 복귀 지점으로 사용
- 플레이어 이동 카메라를 Map의 단일 메인 카메라에 재연결
- 기존 근접 무기·총기·보조장비·소모품 상태 구조 재사용
- 주요 구역의 MapPoint를 통해 안전한 도착 지점 관리
- MapTravelConsole의 F키 상호작용으로 선택적 빠른 이동
- 직접 도로와 옥상 경로를 통한 보행 탐험 유지

빠른 이동은 탐험을 대체하는 필수 이동 수단이 아니라 개발 중 주요 장소를 반복 확인하기 위한 보조 기능이다.
