## 1. 개발 목표와 완료 범위

통합 훈련센터에서 유령손·골목비·청룡선·문지기·천리안을 같은 조건으로 시험하고, 실제 발사·적중·피해·처치 시간과 경비의 청각·탐지 반응을 기록하는 기반을 구현한다.

이번 커밋의 범위는 비교 시험·관측·결과 저장 기능이다. 총기의 피해량·탄약·반동 등 밸런스 에셋을 조정한 작업은 포함되지 않았다. 실제 시험 기록을 검토해 밸런스를 확정하는 작업은 별도 후속 항목으로 남긴다.

## 3. 시험 조건과 사용 흐름

| 항목 | 현재 구현된 선택 또는 규칙 |
|---|---|
| 총기 | 기존 장착 목록의 대표 총기 5종 |
| 사격선 | 통합 훈련센터의 기존 레인 9개 |
| 표적 체력 | 150 / 300 / 600 |
| 표적 방어율 | 0% / 50% |
| 자세 | 정지 조준 / 정지 비조준 / 앉기 조준 / 좌우 이동 조준 |
| 명중 부위 | 자유 / 몸통만 / 머리만 |
| 사격 제한 | 기본 60초, 첫 발사 이후 기준 |
| 무발사 제한 | 준비 후 45초간 발사하지 않으면 NoShot으로 종료 |

F8 또는 계측 단말기의 F키 상호작용으로 설정 화면을 연다. 조건을 선택하면 실제 장비 관리자를 통해 무기를 장착하고, 보급 후 선택한 발사 기준점으로 이동한다. 표적만 임시 복사본으로 바꾼 뒤 직접 사격한다.

계측 화면은 열려 있는 동안 게임 입력과 카메라 제어를 잠시 중단하고, 닫을 때 자신이 변경한 상태를 복원한다. 기존 입력 에셋과 키 배치는 수정하지 않았다.

## 4. 계측 기준

| 기록 | 기준 |
|---|---|
| 발사 수 | 실제 탄약을 소모한 한 번의 발사 |
| 발사 명중 수 | 지정 표적에 펠릿 하나 이상 적중한 발사 |
| 펠릿 명중 수 | 지정 표적에 실제 적중한 개별 펠릿 |
| 머리 적중 | 지정 표적 머리에 맞은 펠릿 수 |
| 실제 피해 | 피격 전후 체력 차이, 남은 체력보다 큰 과잉 피해 제외 |
| TTK | 첫 명중이 아닌 첫 발사부터 지정 표적 제압까지의 게임 시간 |
| 재장전 | 프레임별 상태 관측으로 횟수와 경과 시간 기록 |
| 사격 조건 | 발사 순간 총구·표적 중심 거리, 이동 속도, 조준 진행도, 분산 |

첫 발사로 제압한 경우 TTK가 0초일 수 있으며, 무발사 시험과는 구분한다. 장착·조준 준비 시간은 현재 TTK의 시작점에 포함하지 않는다.

무기 교체·보급·사격선 이탈·다른 공격에 의한 피해·표적 초기화·자세 또는 명중 부위 불일치·창 초점 이탈 등의 조건 위반은 Invalid로 기록한다. 미제압 시간초과는 Timeout, 준비 중 무발사는 NoShot으로 구분한다.

완료 평균에는 Completed 결과 중 시험 조건·무기 ID·무기 설정 해시가 같은 기록만 포함한다. 서로 다른 체력·방어율·자세·무기 수치의 기록을 같은 평균에 섞지 않는다.

## 5. 원본 표적 보존과 실전 관측

통제 시험은 원래 표적을 초기화한 뒤 비활성화하고, 같은 모형과 피격 영역의 임시 표적에 시험 체력·방어율을 적용한다. 종료·중단·컴포넌트 비활성화 시 임시 객체를 정리하고 원래 표적을 복원한다. 완료 후에는 표적 넘어짐을 보여 주기 위해 복원을 잠시 지연한다.

잠입·실전 구역의 관측은 통제 사격 시험과 분리한다. 실제로 실행 중인 구역의 총기 발사·적 피해·센서 청취·직접 시야 변화·탐지 상태 변화를 관찰한다. 센서의 Detected 상태를 전역 경보 발생으로 대체해 기록하지 않는다.

실전 관측은 기본 6,000개 이벤트까지 보관하고, 상한 때문에 제외한 이벤트 수를 함께 기록한다. 통제 시험은 최대 3,000개 발사 샘플로 제한한다.

## 6. 저장과 파일 구성

결과는 `Application.persistentDataPath/BalanceReports/`에 저장한다. 설정 화면에서 실제 폴더 경로를 확인하고 복사할 수 있다.

| 파일 | 내용 |
|---|---|
| trial_고유번호.json | 시험 조건·무기 설정·발사별 상세 측정 |
| trial_고유번호.csv | 시험 한 회의 요약 결과 |
| observation_고유번호.json | 실제 잠입·실전 구역의 관측 사건 |

새 파일은 고유 이름과 FileMode.CreateNew로 기록하여 기존 결과를 덮어쓰지 않는다. CSV는 UTF-8 표시와 지역 설정에 독립적인 숫자 표기를 사용한다. 최근 시험 최대 250개를 비교 목록에 읽는다.

신규 C# 파일은 `Assets/_Project/Scripts/Training/Balance/`의 9개와 `Assets/_Project/Editor/Day15/`의 2개다. 기존 `TrainingShotResolver.cs`와 `DetectionSensor.cs`에는 계측 이벤트 연결을 추가했다.

Test 씬에는 계측 관리자와 참조·로비 단말기 구성이 추가되었다. 변경 전 씬은 `Assets/_Project/Backups/Day15/`에 저장하는 설치 코드를 포함한다. 무기 에셋·입력 에셋·기존 체력바 코드는 이번 비교에서 변경되지 않았다.

## 9. 후속 작업
