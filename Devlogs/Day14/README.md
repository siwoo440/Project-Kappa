## 1. 개발 목표와 일차 구분

기존 Test 맵 옆에 훈련 구역을 이어 붙이던 배치를 정리하고, 로비·장비 준비·사격·파쿠르·잠입·실전 공간을 하나의 통합 훈련센터로 재구성한다. 원래 플레이어와 총기·전투 기능을 유지하면서 반복 시험이 가능한 환경을 만든다.

13일차 일지 다음에 진행한 이번 맵 전면 개편을 14일차 작업으로 기록한다. 기존 기획서의 14일차 항목인 ‘대표 총기 5종 통합 밸런스’를 완료했다는 의미는 아니다. 이번 변경에는 총기 능력치 에셋과 입력 에셋의 수정이 포함되어 있지 않다. 통합 밸런스 측정·조정은 다음 작업으로 남긴다. Google Docs 개발 계획의 일차와 완료 상태는 이번 작업에서 변경하지 않는다.

## 3. 통합 구역 구성

| 구역 | 주요 내용 |
|---|---|
| 01 Lobby | 새 스폰·장비 정비·총기 진열·보급 |
| 02 StaticRange | 5m·10m·20m·30m 독립 사격선 4개 |
| 03 MovingRange | 좌우 왕복 표적을 사용하는 사격선 3개 |
| 04 Parkour | 점프 발판·벽 달리기·앉기 터널·옥상·우회 경사로 |
| 05 StealthBlock | 모의 공장 골목·엄폐·관찰 발판·순찰 경비·감시 장치 시험 |
| 06 LiveArena | 검술·사격을 시험하는 실전 교전 공간 |
| 07 PrecisionRange | 90m·150m 독립 장거리 사격선 2개 |

구역 수는 로비·정비실을 하나로 묶어 총 7개다. 사격선과 표적은 총 9개이며, 이동 표적 3개 안에 이동형 150HP 계측 표적 1개가 포함된다. 고정 사격동의 30m 표적도 150HP 계측용이다. 별도의 신규 표적 피격 시스템을 다시 만드는 대신 기존 `TrainingReactiveTarget`과 13일차 표적 제작 함수를 재사용한다.

## 4. 적 시험과 반복 초기화

- 시험 시작 전에는 보관된 적·감시 장치 원본을 비활성 상태로 유지
- F키 단말기에서 선택한 시험을 시작하면 다른 구역의 실행 시험을 종료
- 내부 시작점으로 이동한 뒤 원본을 복제하여 해당 구역에서만 시험 진행
- 종료 시 복제된 실행 객체만 비활성화·제거하고 원본은 보존
- 플레이어가 구역을 벗어나거나 사망하면 시험 종료
- 실행 중인 적이 구역을 벗어나도 시험 전체를 종료하는 방식으로 처리
- 다시 시작할 때 보존된 원본에서 새 객체를 생성

적의 경계 이탈 처리는 ‘개별 적이 자연스럽게 귀환하는 AI’가 아니라 시험 전체의 안전 종료다. 구역별 원본 위치·순찰 지점과 새 스폰의 안전거리는 검사 메뉴에서 확인하도록 구성되어 있다.

## 5. 기존 기능 유지와 미구현 범위

총기 5종의 수치·반자동/자동/산탄 사격·삽입식 장전·검술·보조장비·소모품·기존 체력바 수정은 이번 개편의 신규 구현 항목이 아니다. 기존 기능을 재사용하고 관련 입력 에셋도 변경하지 않았다.

보급 단말기는 체력·총기 탄약·마비침·소모품을 보충한다. 구역 표적 초기화는 해당 구역의 표적 위치·체력·탄착·넘어짐을 복구하며, 기존 총기 사격 기록도 보급 과정에서 초기화한다.

공식 밸런스 비교 결과, 전체 전투 시간 측정, 무기별 기록의 영구 저장·CSV 출력은 이번 변경에 추가된 것으로 기록하지 않는다. 다음 개발에서 측정 범위와 기록 형식을 정한 뒤 진행한다.
